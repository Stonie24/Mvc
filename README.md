## Setup
Clone the repository:
```bash
git clone https://github.com/Stonie24/Mvc
```

## Install
Install the dependencies:
```bash
cd Mvc
composer install
```

## Usage
Start the local server:
```bash
symfony serve
```

Check available routes:
```bash
php bin/console debug:router
```
